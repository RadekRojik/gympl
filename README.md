Tento repozitář obsahuje výukové příklady a ovladače psané v **MicroPythonu**.  
Cílem je mít přehledný a komentovaný kód, který studentům pomůže pochopit práci se senzory a mikrokontroléry.

### Proč název „Gympl“?
V češtině je *gympl* hovorová zkratka pro *gymnázium* – typ střední školy s akademickým zaměřením.  
Název odkazuje na vzdělávací účel tohoto repozitáře: materiály slouží hlavně pro výuku a samostudium studentů, ale využijí je i hobby nadšenci.

<a name="en"></a>
## 🇬🇧 EN

This repository contains educational examples and drivers written in **MicroPython**.  
The goal is to provide clear, well-commented code to support learning how to use sensors and microcontrollers.

### Why the name “Gympl”?
In Czech, *gympl* is a colloquial abbreviation for *gymnázium* – a type of secondary school with an academic focus.  
The name reflects the educational purpose of this repository: primarily as teaching material for students, but also useful for hobbyists.
